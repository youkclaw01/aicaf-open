# AI Assessment 시스템

현황 수집과 근거 기반 현황분석, 공식 기준에서 파생한 인터뷰, 두 선행 보고서의 종합 분석을 연결하는 포털이다.

## 저장소 범위

- 제품 소스, 결정적 시험, 공식 기준 원문 및 승인된 문서 양식을 관리한다.
- 고객 데이터, 답변, 녹음, 계정 정보, 환경 파일, 작업 원장, 생성 산출물, 고객별 실행·조사 스크립트는 포함하지 않는다.
- 저장소는 비공개다. 공개 범위 변경은 별도 결정 사항이다.

## 개발·동기화·배포

1. 작은 기능 단위로 실패 시험과 수정 범위를 확정한다.
2. 관련 회귀 및 소스 보안 검사를 직접 수행한다.
3. 변경을 커밋하고 GitHub에 동기화한다.
4. 해당 커밋의 파일 목록·해시와 운영 기준을 비교한다.
5. 활성 작업과 인터뷰가 없는 조건에서 백업 후 해당 단위를 배포한다.
6. 인증된 실제 포털에서 화면·접근 조건·요청·결과를 확인한다.
7. 발견한 결함을 다음 작은 수정 단위로 반복한다.

배포 패키지와 실제 적용 파일은 커밋 및 해시로 식별한다. 운영 DB·고객 원본·중지된 고객 개정은 배포 대상으로 삼지 않는다. 로컬 시험 통과, 운영 반영, 실제 모델 생성, 문서 렌더, 다운로드 검증은 별도 증거로 구분한다.

## 최종 검증 기준

신규 프로젝트가 동일 공통 코드로 현황분석 보고서, 인터뷰 보고서, 현황분석 종합·시사점·개선과제 보고서를 생성하고, 검토·저장·복구·재개·렌더·다운로드까지 완료해야 전체 완주로 판정한다. 생성형 모델에 합성 답변을 실제 고객 답변으로 제시하지 않는다.

## 시험 환경

Windows 운영 환경의 SDK와 Office 검증은 별도로 수행한다. 로컬 회귀 결과가 Windows 실제 렌더 또는 운영 포털 검증을 대체하지 않는다. 모델 호출을 수반하는 검증은 기존 모델·비용·승인 정책을 유지한다.
